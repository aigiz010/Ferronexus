# Ferronexus — дизайн-документ

## 1. Энергия
- Внутренняя единица — **RF**. Машины хранят, потребляют и передают только RF (стандартная энергия NeoForge, 1 RF = 1 FE).
- **Универсальный приём энергии.** Любая машина и любой энергоканал Nexus-шины принимают энергию других систем и сразу конвертируют её в RF:
  - конвертация встроена в саму машину — отдельные блоки-преобразователи не нужны;
  - поддержка каждой внешней системы — отдельный модуль совместимости, который загружается, только если эта система есть в сборке (жёстких зависимостей нет);
  - коэффициенты задаются в конфиге `ferronexus-energy.toml` и через датапаки (`data/ferronexus/energy_conversion/*.json`);
  - системы, которые отдают энергию через стандартный интерфейс NeoForge, работают без отдельного модуля.
- Обратная конвертация (RF → чужая энергия) по умолчанию выключена, чтобы не было бесконечных петель. Её можно включить в конфиге с потерями.
- **Ярусы мощности** (максимум RF/t на вход): ULV 8, LV 32, MV 128, HV 512, EV 2048, IV 8192, LuV 32768, ZPM 131072, UV 524288.
- Если на машину приходит больше её яруса, она перегревается (можно отключить в конфиге). Ограничение считается уже после конвертации в RF.
- Провода различаются пропускной способностью (RF/t) и потерями на блок.

## 2. Материалы
Реестр материалов на основе данных: металлы, сплавы, кристаллы, химикаты. Для каждого материала автоматически создаются формы: слиток, пыль, малая и мелкая пыль, пластина, стержень, шестерня, проволока, фольга, винт, блок, жидкость, газ.

## 3. Переработка руд
| Ступень | Цепочка | Выход |
|---|---|---|
| ×2 | Дробитель → Печь | 2 слитка |
| ×3 | Обогатитель (кислота) → Очиститель | 3 |
| ×4 | Инжектор хлора → Кристаллизатор | 4 |
| ×5 | Растворитель → Химический реактор → Кристаллизатор | 5 |

На каждой ступени появляются побочные продукты.

## 4. Машины
- **Одноблочные**: дробитель, электропечь, пресс, экструдер, волочильня, проволочный станок, центрифуга, электролизёр, смеситель, химический реактор, сборщик, лазерный гравёр.
- **Многоблочные**: доменная печь Nexus, вакуумный морозильник, крекинг-установка, ректификационная колонна, термоядерный реактор, сборочная линия.
- **Генераторы RF**: на угле, паровая турбина, газовая турбина, солнечные панели, термоядерный реактор.
- **Апгрейды**: скорость, энергоэффективность, параллельная обработка, фильтры, автовывод.
- **Стороны блока**: для каждой стороны настраиваются вход, выход, приоритет и автовыталкивание.

## 5. Nexus-шины (одна шина — много каналов)
Один блок вмещает до 9 разных каналов.
- Каналы: энергия (RF, принимает любую энергию с конвертацией), жидкости, газы, предметы, редстоун (16 цветов), сетевой канал хранилища (опционально).
- Блок рисуется как пучок труб. При наведении курсора подсвечивается конкретный канал.
- Каналы добавляются и снимаются правым кликом, гаечный ключ выбирает канал.
- Настройки на каждой грани: режим (вход / выход / оба / выкл), фильтр, приоритет, канал-цвет, редстоун-контроль.
- Можно закрыть блок фасадом: шина примет вид любого блока.

## 6. Импринтер (копирование структур)
Предмет-инструмент для копипаста.
- **Выделение**: ПКМ по двум углам, или Shift+ПКМ, чтобы автоматически захватить всю многоблочную структуру.
- **Что копируется**:
  1. блоки и их состояния (направление, ярус);
  2. настройки машин: стороны, режимы, апгрейды, приоритеты, рецепт-лок;
  3. настройки Nexus-шин: каналы, режимы граней, фильтры, цвета;
  4. по желанию — **содержимое** (инвентари, жидкости, энергия). В выживании — только для админа или за дорогую плату.
- **Вставка**: голографический предпросмотр, поворот (R) и зеркало (M). Недостающие материалы берутся из инвентаря игрока или подключённой сети хранения.
- **Режим «Настройки»**: применяет скопированные настройки к уже стоящим блокам, ничего не строя.
- **Хранение**: схемы записываются в предмет-картридж и экспортируются в файл `.fnx` (NBT + сжатие).

## 7. Текстуры
Текстуры 16×16, металлическая палитра в индустриальном стиле. Каждый материал окрашивается своим цветом через tint, поэтому одна текстура-основа служит для многих материалов. Ярусы машин различаются цветом корпуса.
