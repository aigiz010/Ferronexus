# Ferronexus

Технический мод для **Minecraft 26.3 / NeoForge 26.3.0.52**.

Длинная индустриальная прогрессия: машины на **RF** с ярусами мощности, многоступенчатая переработка руд, химия и газы, универсальные **Nexus-шины** (несколько каналов в одном блоке) и **Импринтер** для копирования построек.

Все текстуры, модели и код — оригинальные.

## Основные системы
1. **Энергия RF.** Все машины работают на RF и **принимают энергию любого типа**, автоматически конвертируя её в RF.
2. **Машины** одноблочные и многоблочные, с улучшениями и ярусами мощности.
3. **Переработка руд** ×2 → ×3 → ×4 → ×5.
4. **Химия и газы**: водород, кислород, хлор, пар, плазма.
5. **Nexus-шины**: до 9 каналов в одном блоке — энергия, жидкости, газы, предметы, редстоун, сетевой канал хранилища.
6. **Импринтер** — копирование структур вместе с содержимым и настройками.

Подробности: `docs/DESIGN.md`, план разработки: `docs/ROADMAP.md`.

## Сборка
Нужен JDK 25.
```
./gradlew build
./gradlew runClient
```
> Gradle Wrapper (`gradlew`, `gradle/wrapper/*`) возьмите из официального NeoForge MDK для 26.3 или создайте командой `gradle wrapper`.
